# Samadhi Hansika Portfolio

A modern personal portfolio website built with React and Vite. It showcases professional experience, education, skills, projects, GitHub activity, and contact details in a clean, responsive layout.

## Features

- Hero section with profile overview and call-to-action
- About section with background and strengths
- Education and experience highlights
- Skills and technology stack
- Featured projects with visuals and links
- GitHub section for project activity
- Contact section for inquiries and networking
- Responsive design for desktop and mobile devices

## Tech Stack

- React
- Vite
- CSS
- Framer Motion
- Lucide React

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
